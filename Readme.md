Result_Management

Result_Management is a lightweight web-based application designed to help teachers efficiently manage student results. The system allows teachers to enter student details, validate input data, and view all results in a clean, organized table format.
It is built using HTML5, CSS3, JavaScript, and Bootstrap, keeping the interface simple, responsive, and easy to use.

✨ Features
✔ Add Student Results

Teachers can input Roll Number, Name, Date of Birth, and Score.

Validations ensure all fields are filled properly.

Score must remain within the 0–100 range.

✔ View All Results

Displays each student’s record in a tabular format.

Easy toggle between form view and results view.

✔ Real-Time Validation

Shows small error messages for wrong or missing input.

Prevents invalid entries like negative scores or values above 100.

✔ Clean & Human-Friendly Code

Code is written in a simple, natural, student-friendly style with basic functions and readable formatting.

✔ No Backend Required

Entire project runs on the client side using JavaScript arrays.

Easy to deploy, test, and demonstrate.
